# Сквозной запуск: этап 5

Control API резервирует одного подключённого агента и отправляет `PrepareAssignment`. После `AssignmentReady` координатор сохраняет манифест через `ResultsIngestion.PutRunManifest` и только после подтверждения отправляет `StartAssignment`. Агент не запускает второй движок при повторе Start текущего назначения. Heartbeat и аренда ограничивают работу при потере управления.

Агент отправляет секундные дельты и финальный пакет в `latencystorm.results.v1`. Ключ Kafka — `assignmentId`, значение — ProtoJSON. Публикация отделена от генерации ограниченной очередью. Results Service сохраняет ожидаемые пакеты в `result_batches` и подтверждает Kafka offset после записи. Манифест и терминальные метаданные хранятся в `run_manifests`. REST-статус запуска не означает, что все измерения сохранены.

## Проверка

Из корня репозитория, в PowerShell с запущенным Docker:

```powershell
docker compose -p latencystorm-stage05 --env-file deploy/compose/.env.example -f deploy/compose/compose.yaml up --build --wait
./tests/infrastructure/stage05.ps1
docker compose -p latencystorm-stage05 --env-file deploy/compose/.env.example -f deploy/compose/compose.yaml down
```

Тест выполняет естественное завершение, ручную остановку и остановку до старта. Он проверяет наличие манифеста, последовательность пакетов, финальное состояние и счётчики в отдельной БД Results Service.

## Ограничения

- Один агент, один координатор и один активный запуск. Внутренние gRPC-порты используют HTTP/2 без TLS и не публикуются на хост. Стенд предназначен для доверенной локальной сети и контролируемого Demo Target, не для общего доступа.
- Буфер доставки находится в памяти. При исчерпании попыток, переполнении или разрыве сессии пакеты могут быть потеряны. Перезапуск не возобновляет старый запуск. Терминальные метаданные передаются с ограниченным временем ожидания; пакет измерений и манифест сохраняются независимо.
- Отчёты, карантин некорректных событий и оценка полноты относятся к этапу 6; распределение нагрузки между агентами — к этапу 7.
